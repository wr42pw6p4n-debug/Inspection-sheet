# Key Engineering Crane Service Report v7

Added report numbering and report search.

- Auto-generates Report Number in the format KE-YYYY-0001.
- Report number is saved with every report.
- Report number appears on the PDF and printable report.
- PDF filenames start with the report number.
- Saved Reports can be searched by report number, customer, crane number, ID, engineer, date or visit type.
- Existing v6 OneDrive sync and other app features are retained.
